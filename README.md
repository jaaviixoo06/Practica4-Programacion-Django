# Tienda de Pulseras & Llaveros (práctica Django)

## Objetivo
Implementar una tienda online sencilla con Django para gestionar productos (pulseras/llaveros), clientes, vendedores y pedidos siguiendo el patrón MVT.

## Qué incluye
- Modelos: Customer, Seller, Product, Order, OrderItem.
- Templates: listado, detalle, carrito en sesión, checkout, lista de pedidos.
- Admin: gestión de clientes, vendedores, productos y pedidos.
- Estética: Bootstrap + CSS personalizado (archivo `styles.css`).
- Entregables: este proyecto, documento explicativo (este archivo) y recomendación para grabación de presentación.
